## 基座重构

- 统一 `backend`、`frontend` 目录，移除 Demo，保留用户、角色、菜单/按钮权限、文件、审计和任务调度。
- 后端统一 YAML 配置，支持 SQLite/PostgreSQL、可选 Redis 缓存及本地/S3/MinIO 文件存储。
- 桌面支持本地 SQLite 和远程 HTTPS 服务，提供连接设置、自定义 CA、独立数据与凭据隔离。
- 修复管理员保护、权限范围、菜单树与并发修改；完善文件流式传输、任务恢复、审计与桌面凭据服务超时处理。
- 修复 Windows 桌面规范化路径与 SQLite URI 的兼容性，并加入首次启动、重启回归检查。
- 更新 Go 工具链、部署示例、中文文档和跨平台构建流程。

## 下载与部署

提供 Linux amd64/arm64 服务压缩包、Linux x64 桌面 deb/AppImage、macOS arm64/x64 app/DMG，以及 Windows x64 安装包。桌面制品未签名、未公证；按操作系统正常安装提示操作。

**本版本采用新的数据库基线，不提供旧数据库或旧安装目录的自动兼容迁移。升级前备份数据，并在新数据目录部署；本地和远程数据不自动同步。**
